# Daiane Mendonça — Portfólio

Site editorial responsivo e trilíngue (português, espanhol e inglês).

## Visualizar localmente
Abra `index.html` em um navegador. Mantenha os arquivos de imagem e o PDF na mesma pasta.

## Publicação gratuita no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em Settings > Pages, selecione Deploy from a branch, `main` e `/root`.
4. Aguarde a publicação do endereço gratuito fornecido pelo GitHub Pages.

## Antes de publicar
- Confirmar se todos os indicadores estão autorizados para divulgação e se as bases de comparação estão corretas.
- Revisar as descrições dos cases e a atribuição individual/coletiva dos resultados.
- Confirmar autorização para exibir marcas, nomes e informações de clientes.
- Revisar a foto e o recorte em dispositivos móveis.
- Atualizar o currículo PDF quando houver nova versão.

Arquivos: `index.html`, `daiane-foto.jpg`, `resultados.png`, `curriculo-daiane-mendonca.pdf`.
